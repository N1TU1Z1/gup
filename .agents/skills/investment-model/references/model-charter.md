# 模型章程

## 目标

模型研究的是未来状态概率及其变化，不把价格低位、低估值、行业叙事、极度悲观或技术形态单独视为 Alpha。

## 五个对象

- `PF = P(公司基本面在定义期限内改善 | 当前证据)`。
- `M_t = (SentimentLevel_t, ΔSentiment_t, Δ²Sentiment_t)`，表示市场情绪状态及变化。
- `L_t`，表示由迟滞规则维护的当前引擎路由锁。
- `H(h) = {H1...Hk}`，表示同一期限和结算规则下互斥且穷尽的未来状态分区。
- `PR(h) = P(市场在 h 个交易日内重新定价 | 当前市场与交易证据)`。

`PF` 由本模型维护；本模型在需要时冻结 `M_t`、`L_t`、`H(h)` 和引擎路由；`PR(h)` 由交易生命周期维护。它们相关时不得假装独立机械相乘，最终使用带概率的联合情景收益计算期望值。

交易层真正关心的是：

```text
P(上涨_h | Fundamental, Valuation, Sentiment, MarketRegime)
```

市场状态是条件变量，不是给 `PF` 加减分的第六个基本面因子。相同基本面证据在不同 `M` 下可以对应不同的重定价路径，但不能对应两套被事后改写的基本面事实。

`M_t` 是 T0 当前状态，只能有一个主状态；`L_t` 是实际启用引擎的锁；`H(h)` 是未来结算状态集合。迟滞期间 `M_t` 与 `L_t` 可以暂时指向不同路线，但不得用路由锁改写当前状态。`E6` 当前状态与“未来持续修复”不是同一个事件，不能共用概率或结算标签。

## 核心原则

1. 因果机制先于分数。
2. 相对竞争优势先于公司自身改善。
3. 资本效率与改善幅度同时评价。
4. 周期改善与长期终值改善分开。
5. 主题热度必须经过收入、利润和现金流兑现。
6. 模型必须允许被未来数据证伪。
7. 公司当前质量与未来继续改善概率分开。
8. 情绪水平与情绪变化分开；极值不等于反转。
9. 新信息只通过预先定义的状态和似然更新概率，不能按结果倒推权重。
10. 精确事实必须可追溯，推断不得改写为已确认事实；数据不足允许 `unknown` 或 `unclassified`。
11. 未来状态必须同期限、互斥且穷尽；相关证据不能伪装成独立证据重复加权。
12. 连续失败或连续下跌不自动提高成功概率；只有可识别失败机制被削弱，才允许调整剩余状态的相对概率。
13. 状态分类与引擎切换分开；迟滞锁的进入、退出、驻留和确认规则必须在 T0 冻结并版本化。

## 研究门槛与交易桥接

先执行第零门：财务数据、审计意见、治理、重大会计更正、法律/税务权利基础是否足以支持判断。第零门失败时只能输出范围、缺失证据或否决原因。

随后五问决定是否允许估计 `PF`：

1. 发生了什么可验证变化？
2. 变化如何提高未来利润或现金流概率？
3. 公司相对竞争者是否改善？
4. 改善消耗了多少新增资本？
5. 改善是周期性还是结构性？

前五项是基本面否决门槛，不能用总分抵消。通过后再记录第六项：

6. 市场当前隐含了什么增长、盈利或份额预期？

第六项只形成 `market_implied_expectation` 证据快照，不改变 `PF`，也不计算买卖点或 `PR(h)`；期限相关的重定价概率和情景期望值由 `$trade-lifecycle` 独占。

## 状态条件化原则

- 乐观市场主要寻找“经济价值改善尚未被价格充分兑现”，但仍检查拥挤和好消息钝化。
- 悲观市场主要寻找“情绪仍差但最坏状态的相对可能性正在下降”，但仍要求基本面生存底线、治理和永久损失风险通过。
- 转折市场主要寻找“坏消息失效 + 好消息重新有效”，单次抗跌、超卖或缩量不足以确认。
- 三门类比表示新证据改变条件概率；其正式实现是 `State Elimination`（状态消除/降权），不表示价格行为能够确定性排除某个未来状态。

## 三门、状态消除与彩票原则

三门逻辑要求先冻结状态全集，再用新信息更新：

```text
Hi ∩ Hj = ∅  (i ≠ j)
H1 ∪ ... ∪ Hk = Ω
ΣP(Hi | I) = 1
```

无法证明穷尽时必须增加 `H_other`，不能把未解释结果强塞进最接近的叙事。点概率必须归一；使用区间时至少满足“下界和不超过 1、上界和不低于 1”，并标注区间不是唯一概率分布。

每条新证据只能把状态记为 `ruled_out`、`downweighted`、`unchanged` 或 `upweighted`。`ruled_out` 只用于在冻结期限和结算规则下已经不可能成立的状态；失败机制只是暂时没有出现时不得使用。股票没有“三门问题中必有一个奖品”的外部保证，排除一个失败状态不等于成功状态必然发生，其他失败状态和 `H_other` 必须继续保留。

彩票逻辑不是追逐低概率暴涨，而是把冻结的未来状态交给交易层附加可成交净赔付：

```text
EV(h) = Σ[P(Hi) × NetPayoff(Hi, h)]
```

本模型只输出状态分区、概率来源和赔率输入。`PR(h)`、成本、滑点、T+1、流动性及期望值由 `$trade-lifecycle` 维护。尾部风险若可能出现在多个状态中，必须作为各状态的条件损失或展开为联合终局，不能再作为重叠的“额外互斥情景”。
