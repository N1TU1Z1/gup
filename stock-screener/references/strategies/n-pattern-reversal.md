# N字修复候选形态

本文件只识别急跌后的修复结构。急跌不是机会本身，价格收复也不能证明基本面反转。

## 待验证假设

非公司特有利空造成的急跌，若随后出现放量收复和板块同步修复，可能代表短期抛压缓解。必须区分市场冲击、公司风险和高位出货。

## 召回条件

1. 3-5个交易日跌幅超过20%，或出现连续极端下跌。
2. 随后3-5日收复原跌幅50%以上。
3. 收复阶段成交量高于近期均量，且具有实际可成交性。
4. 急跌前不是大幅上涨后的高位，或高位风险已经单独标记。

## 结构分类

- 标准N字：急跌、短暂整理、再收复。
- V形修复：急跌后直接收复，波动和失败风险更高。
- 双底修复：二次回落未破前低后收复。
- 弱修复：收复不足50%，仅保留观察。

分类是描述字段，不代表可靠性等级或收益承诺。

## 降级与淘汰

- 减持、业绩、监管等公司特有利空尚未解除。
- 高位N字、无量收复、再次跌破急跌低点或板块继续走弱。
- 无法区分市场冲击和公司事件时，标记原因未确认。

## 输出字段

```text
代码、急跌区间、收复比例、量能、结构分类
急跌原因、板块同步性、信号状态、尚未确认项、淘汰条件
```

## 数据核验

- 用 `eltdx_kline` 计算急跌与收复比例，用 `eltdx_quote`、`eltdx_minute` 核验当前状态。
- 用 `eltdx_company_news`、`eltdx_hot_topics` 检查原因，用 `eltdx_topic_stocks` 核验板块同步性。
