# 因果与概率框架

## 因果链

对每家公司依次验证：

```text
行业需求或供给变化
-> 受益技术路线
-> 公司相对份额
-> 收入兑现
-> 毛利与利润兑现
-> 现金流与资本回报兑现
```

每条边记录 `confirmed`、`inferred` 或 `unknown`，并附证据时间。任一关键边为 `unknown` 时，不得把行业成功概率直接赋给公司。

## 定义与可靠性门槛

冻结前先定义期限、改善事件、阈值和会计口径。不得在验证时把“归母净利润改善”替换成“扣非利润改善”，或用归母 ROE 验证扣非利润假设。

以下事项属于前置可靠性门槛：

- 非标审计、重大会计差错更正或审计证据受限。
- 关键合同、牌照、土地、补贴、税收优惠等权利基础不确定。
- 关联交易、资金占用、担保或治理事项可能改变利润和现金流解释。
- 核心分部、客户、订单或现金流数据不足以复核因果链。

关键门槛失败时降低数据置信度、扩大 `PF` 区间或停止精确估计，不用估值低、题材强或现金流暂时转正抵消。

## 概率链

可以用条件概率帮助拆解：

```text
P(企业改善)
= P(行业成立)
× P(路线成立 | 行业)
× P(获得份额 | 路线)
× P(收入兑现 | 份额)
× P(利润兑现 | 收入)
```

这不是要求主观数字机械相乘。若事件相关、数据不足或定义不清，使用区间和情景表达，并解释依赖关系。

## 相对竞争优势

至少选择一个直接竞争者或可解释的行业基准，比较：

- 市占率变化。
- 公司毛利率变化减竞争者毛利率变化。
- 公司 ROIC 变化减行业 ROIC 变化。
- 产品、客户、量产和产能利用率进度。

## 资本效率

优先观察：

```text
改善效率 = ΔNOPAT / ΔInvestedCapital
```

同时检查自由现金流、资本开支、负债和产能利用率。收入改善但资本效率恶化时不得给出高质量改善结论。

## 利润与现金流口径

若利润门槛采用扣非/核心利润，则增长率和 ROE 使用相同口径。至少同时保留归母与核心口径，解释差额来源。

经营现金流必须建立桥接：

```text
经营现金流
= 核心利润
+ 非现金费用
+ 存货释放
+ 经营性应收释放
+ 经营性应付增加
+ 其他经营项
```

把合同退款、保证金、税费返还、资产处置相关流入及其他一次性项目单列。利润下降而现金流上升时，先判断是经营质量改善还是营运资本释放。

## 改善类型

| 类型 | 默认持续性 | 主要验证 |
|---|---|---|
| 库存周期 | 低 | 库存、价格、补库节奏 |
| 供需周期 | 中低 | 供给退出、产能、需求增速 |
| 市占率提升 | 中高 | 相对销量、客户与份额 |
| 护城河增强 | 高 | 资本回报、定价权与替代成本 |
| 混合 | 不确定 | 分解后分别评价 |

周期盈利恢复不能直接提高长期终值。

## 公司质量与改善概率

- `quality_state` 描述当前护城河、盈利质量、资产负债表和资本效率。
- `PF` 描述从当前基线继续改善并达到冻结阈值的概率。

高质量、高基数公司可能只有中低 `PF`；低基数公司可能有较高改善概率但质量仍差。两者不得相互替代。

## 独立驱动情景

乐观、基准、悲观只是结果名称，不能让所有变量机械同向。每个情景分别说明：

- 收入：行业需求、路线份额、销量和价格。
- 利润率：产品组合、利用率、成本和竞争。
- 营运资本：存货、应收、预付款和应付。
- 资本开支与资本效率：投产进度、利用率和新增回报。
- 治理、审计、法律和税务：发生概率、影响范围和可逆性。

允许出现“收入改善但毛利率下降”“利润下降但经营现金流暂时上升”等非共单调情景。

## 主题兑现率

按以下链条判断叙事是否转化：

```text
主题热度 -> 可核验订单 -> 相关收入 -> 相关利润 -> 经营现金流
```

概念关联强但业务收入、利润或客户验证弱时，标记“高主题暴露、低盈利兑现”。
