# 模型评估与反思

用市场证伪模型，而不是用模型事后解释市场。

## 开始前

- 计算或解释绩效时读取 [指标定义](references/metrics.md)。
- 进行失败归因或模型升级时读取 [反思与版本规则](references/reflection-and-versioning.md)。
- 查询或写入台账时读取 [数据结构](references/schema.md)。

## 评价前提

只评价在 `T0` 已冻结且具有以下字段的实验：

```text
experiment_id、hypothesis_id、model_version、evidence_as_of
评价期限、基准、PF、PR(h)、预测成功概率、情景与失效条件
```

实验未到期、基准缺失、未来可见数据污染或结果不可成交时，保持开放或标记无效，不进入胜率。

## 评价流程

1. 使用冻结时定义的起点、期限、基准和收益口径。
2. 计算实际收益、基准收益、超额收益、MFE、MAE、最大回撤和反弹恢复率。
3. 同时报告样本数、胜率、平均收益、盈亏比、利润因子和概率校准；没有样本时显示 `N/A`。
4. 分开判断“决策质量”和“结果质量”，不把盈利自动当作好决策。
5. 将偏差归入固定错误类型，记录证据与反事实。
6. 单个案例只能形成修订提案；满足样本量和样本外验证后才创建新模型版本。

## 数据纪律

- 胜率必须按模型版本、持有期限和市场环境分组；不同定义的样本不得混算。
- 持平样本进入胜率分母；无效样本不进入。
- 预测概率必须使用 `T0` 冻结值。禁止用最新判断覆盖后再计算校准。
- 只有用户明确要求记录或结算时才写数据库；普通解释保持只读。
- 可运行 `scripts/model_scorecard.py` 只读查询模型绩效视图，禁止脚本修改数据库。

## 输出

先给模型是否得到支持，再给最少必要指标：

```text
模型版本、期限、样本数、胜率及区间
平均超额收益、盈亏比、利润因子、MFE、MAE、最大回撤
预测概率与实际命中率、Brier分数
决策质量、结果质量、错误类型、反事实
维持/观察/提出修订/拒绝修订
```
